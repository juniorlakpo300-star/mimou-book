# AGENTS.md

## Project
This repository is a book-sharing and reading platform called `mimou-book`.

The project is currently a minimal starter and is expected to evolve toward a simple web application for discovering, sharing, and reading books online.

## Working rules for agents
- Keep changes small, readable, and aligned with the project goal.
- Prefer simple, maintainable implementations over adding heavy dependencies without a clear need.
- If no stack is specified, avoid inventing a large framework unless the task explicitly requires it.
- Update documentation when behavior, setup, or architecture changes materially.
- Do not add unnecessary files or generated artifacts.
- Favor clear naming, modular code, and consistent project structure.

## Repository expectations
- Preserve a clean root structure.
- If the project grows, keep application code separated from configuration and documentation.
- For frontend work, prefer accessible HTML/CSS/JS patterns unless a framework is already chosen.
- For backend or API work, keep endpoints consistent and validate inputs where relevant.

## Validation
- Run the smallest relevant checks available for the change.
- If no automated tests exist, validate with a simple local run or script that demonstrates the behavior.
- Report any limitation clearly if validation cannot be performed.

## Communication style
- Be concise and practical.
- Explain assumptions when choosing an implementation approach.
- Call out any missing requirements rather than guessing.

## Preferred workflow
1. Understand the task and repository state.
2. Make the minimal change needed.
3. Validate the affected behavior.
4. Summarize the result clearly.
